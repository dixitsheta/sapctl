# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be respectful. Disagreement is fine; personal attacks are not.
- No harassment, discrimination, or sexualised content in any project space
  (issues, PRs, Discord, conferences, DMs).
- Project maintainers can ban anyone violating the above without warning.

## Reporting

Email **conduct@sapctl.dev**. Reports are read by the project lead only.
Anonymous reports accepted via the [contact form](https://sapctl.dev/contact)
with topic "Other".

## Scope

Applies to all project spaces and to people representing the project in
public (talks, conferences, social media posts tagging the project).
