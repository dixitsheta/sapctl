## Why sapctl

<CardGrid>
  <Card title="One CLI, all SAP" icon="approve-check">
    Single binary, single auth model, single command tree across the SAP
    portfolio. Stop maintaining glue code per migration.
  </Card>
  <Card title="Agent-native" icon="puzzle">
    Every command is exposed as an MCP tool over `sapctl mcp serve`. No
    SDK porting required for AI agents.
  </Card>
  <Card title="CRA / DORA evidence by default" icon="seti:lock">
    Every run emits a hash-chained, ed25519-signed audit event. Recipes
    (SOX, DORA, AI Act, CRA) generate auditor-ready bundles.
  </Card>
  <Card title="Air-gap ready" icon="rocket">
    `sapctl bundle export` produces in-toto-signed tarballs verifiable on
    disconnected machines.
  </Card>
</CardGrid>

> Independent open-source project. Not affiliated with SAP SE.
