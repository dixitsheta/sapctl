Summary

We set no third-party cookies, run no advertising trackers, and use no cross-site identifiers. Analytics are self-hosted, cookie-free, and aggregated. You can browse this site with cookies disabled; only your light/dark preference will not persist.

Analytics

We run a self-hosted instance of Plausible behind events.sapctl.dev. It does not set cookies and does not use cross-site identifiers. The data we collect is described in the privacy policy.

Embedded content

Some documentation pages embed code samples from GitHub Gist or short MP4 demos served from our own CDN. These do not set cookies. We never embed YouTube, Vimeo, or other tracker-heavy players on the marketing site.

How to control cookies

You can clear cookies and local storage at any time via your browser settings. On modern browsers you can also restrict storage on a per-site basis. Doing so will not break the site; only theme persistence and form submissions will be affected.

Changes

We will update this page within 14 days of any change to our cookie use and post a notice at the top.
